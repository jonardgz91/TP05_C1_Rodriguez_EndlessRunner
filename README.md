# ESPAÑOL
# TP05_C1_Rodriguez_EndlessRunner
Desarrollado por: Jonathan Rodríguez
https://jonardgz.itch.io/

## Objetivo
Sumar la mayor cantidad de puntos.

## Controles
Saltar: Espacio
Escape: Pausa

## Reglas de juego

El personaje avanza sin parar y los enemigos aparecen de forma continua. Cada choque te saca una vida; cuando te quedás sin vidas, se termina la partida. El objetivo es sobrevivir el mayor tiempo posible.

## Menú principal
- **Start Game**: inicia la partida.
- **Settings**: permite personalizar el sonido.
- **Credits**: créditos del proyecto.

## Personalización (Settings)

Se puede ajustar el sonido de:
- **Master** volumen general del juego.
- **Backgroud** volumen de la musica de fondo.
- **SFX** volumen de los efectos.
- **UI** volumen de la UI.

## Fin de la partida
Al perder todas las vidas.

# ENGLISH
# TP05_C1_Rodriguez_EndlessRunner
Developed by: Jonathan Rodríguez
https://jonardgz.itch.io/

## Objective
Score as many points as possible.

## Controls
Jump: Space
Pause: Esc

## Game Rules

The character runs forward non-stop while enemies keep spawning. Each hit costs you one life; when you run out of lives, the game is over. The goal is to survive as long as possible.

## Main Menu
- **Start Game**: starts a new run.
- **Settings**: lets you adjust the audio.
- **Credits**: project credits.

## Customization (Settings)

You can adjust the volume of:
- **Master**: overall game volume.
- **Background**: background music volume.
- **SFX**: sound effects volume.
- **UI**: UI sounds volume.

## Game Over
The game ends when you lose all your lives.
